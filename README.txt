AFSHAR BIRTHDAY WEBSITE
1. Create a new GitHub repository (for example: afshar-birthday).
2. Upload index.html, style.css, script.js and the entire assets folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch: main and folder: /(root), then Save.
6. Wait for GitHub Pages to publish your site.

The site is mobile-first and uses the six supplied photos.
Before publishing, review the photos and letter text and change anything you want.
